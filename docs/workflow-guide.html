Daily routine

  1. Open WezTerm. It starts ~/.local/bin/herdr and attaches local default session.
  2. Click existing workspace, or press Ctrl-B, then up for Herdr Plus Projects.
  3. Press Ctrl-B, then t when you know fuzzy name but not location.
  4. Review and apply dotfiles from source checkout.
  5. Detach with Ctrl-B, then q. Pane processes keep running.
cd ~/.local/share/chezmoi
chezmoi diff
chezmoi apply
chezmoi verify

Remote terminals

DelftBlue: plain SSH tab

Use DelftBlue in Remote shells. SSH keepalive runs every 30 seconds with three missed replies allowed. Run kinit when /tudelft.net credentials expire.

CerpacNAS: full remote Herdr

  1. Press Ctrl-B, then t.
  2. Type CerpacNAS or filter remotes with Ctrl-S.
  3. Select target. The integration clears only the inherited HERDR_ENV marker, then runs herdr --remote cerpacnas --handoff.
  4. Use NAS server's separate persistent sidebar.
  5. Detach with Ctrl-B, then q; reopen through Picker Plus.

Herdr's global allow_nested safety guard stays disabled. The narrow environment cleanup is required because Picker Plus 0.2.0 otherwise mistakes an intentional remote handoff for a nested local Herdr launch.

Remote Herdr 0.7.3 lives at /root/.local/bin/herdr. Remote attach manages SSH keepalive and connection reuse.

Can Codex Desktop control Herdr?

Not local panes directly. Desktop runs outside Herdr, so HERDR_ENV is unset. Herdr skill refuses pane/workspace control unless HERDR_ENV=1. Do not fake variable.

Desktop can manage config, plugins, server status, and outer remote client:

herdr status server
herdr server reload-config
herdr plugin list
herdr --remote cerpacnas

Full control: start Codex CLI inside Herdr

  1. Open desired Herdr pane.
  2. Run codex there. This is separate CLI task.
  3. Confirm HERDR_ENV=1.
  4. Ask that agent to use Herdr skill; it can list, read, split, run, send, and wait across panes.
# fish
test "$HERDR_ENV" = 1; and echo ready

# sh/bash/zsh
test "$HERDR_ENV" = 1 && echo ready

For NAS control, attach CerpacNAS first, then run codex in remote Herdr pane. Desktop conversation cannot be transplanted; start new CLI task or give it handoff prompt.

CerpacNAS agent workflow

nas is daily interface. Code moves through Git/JJ bookmarks, config through chezmoi dev, artifacts through allowlisted rsync plans. Agents remain below /root/Projects and never use sudo, Docker, or dangerous bypasses.

nas doctor
nas projects status thesis
nas projects sync thesis
nas handoff thesis my-task --to nas --push
nas agent start thesis my-task --mode explore -- "Inspect requested seam"
nas agent status
nas validate thesis my-task web-type
nas handoff thesis my-task --to mac --push

Use --push only when publication is intended. Project sync never merges, rebases, pushes, deletes, or mirrors live repositories.

GitHub token policy: nas doctor verifies repository access. Legacy broad OAuth scopes are reported as a warning, not rejected, so existing trusted credentials keep working.

Artifacts

nas artifact plan thesis data --direction push
nas artifact push thesis data --apply

Apply consumes one-hour receipt. Git metadata, credentials, dependencies, and caches stay excluded.

Tools and Homebrew

chezmoi apply reconciles adapters from .chezmoidata/packages.yaml. Fingerprints live under ~/.local/state/chezmoi/tool-reconcile; only changed/missing families run. Undeclared tools are not removed.

AeroSpace shortcuts

Cmd-Ctrl-Alt-9 ensures one dedicated raw WezTerm window is running btop, moves it to AeroSpace workspace 9, and switches there. It reuses the existing window instead of opening duplicates.

AeroSpace also creates the btop window at startup without stealing focus. Ordinary new WezTerm windows still launch or attach Herdr.

Keyboard workflow

kbd provision is sole lifecycle entrypoint. It checks prerequisites, prepares QMK, activates VirtualHID, and installs Kanata. Follow exact System Settings instruction when permission is missing, then rerun.

Repo-local mise run kbd_* tasks require chezmoi checkout; run mise trust there once if needed.

DelftBlue profile

Profile stays conservative: bash default, no workstation package manager, home-local tools, compute work off login node.

dbdev-bootstrap   # once, login node

dbscratch         # move to scratch

Long work belongs in Slurm jobs under ~/.config/delftblue/jobs/. Use dbpush/dbpull for large outputs.
